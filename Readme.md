# Adaptive Market Regime & Volatility Intelligence System

## Overview

An empirical financial data science project investigating whether
equity derivatives and global financial-market information improve
out-of-sample volatility and risk forecasting for the Indian equity
market.

## Primary Market

NIFTY 50 / NSE

## Core Dataset

- NIFTY 50
- India VIX
- NIFTY Futures
- Selected NIFTY Options
- S&P 500
- US VIX
- US 10-Year Treasury Yield
- USD/INR
- Brent Crude

## Primary Target

Future 5-day realized volatility.

## Methods

- Financial time-series analysis
- EWMA
- GARCH
- Derivatives-based features
- Machine learning
- Market-regime analysis
- VaR
- Expected Shortfall
- Stress testing

## Outputs

- Research paper
- Research dataset
- Risk intelligence system
- Streamlit application
- Power BI dashboard
